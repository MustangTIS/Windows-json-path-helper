JSON Path Helper

Windows のファイル／フォルダパスを、JSON 文字列として扱いやすい形式へ素早く変換・コピーするための GUI ツールです。  
エクスプローラーの「パスのコピー」で付くダブルクォーテーション（`"`）や前後の空白・改行を自動で整え、対象パスと親フォルダパスの両方を二重バックスラッシュ（`\\`）およびスラッシュ（`/`）形式で出力します。

主な機能

入力の自動整形：
	前後の空白・改行や、囲みダブルクォーテーション（`"C:\...\file.txt"`）を自動で除去して変換します。

多様なパス入力に対応：
	入力欄への直接入力・貼り付け（リアルタイム変換）
	ファイル / フォルダ ボタンからのダイアログ選択（現在の入力パスを初期フォルダとして推測）
	クリップボードから取得 ボタンによるワンクリック取り込み

4パターンの変換出力とワンクリックコピー：
	対象パス (\\)：C:\\path\\to\\target
	対象パス (/)：C:/path/to/target
	親フォルダ (\\)：C:\\path\\to
	親フォルダ (/)：C:/path/to

コピー後に自動で閉じるオプション：
	連続で貼り付け作業を行う際にウィンドウを自動で閉じられます。

動作環境
	OS：Windows
	Python：3.x（標準ライブラリ tkinter、pathlib のみ使用／追加パッケージ不要）

使い方
	1.バッチファイルから起動する場合
		`json_path_helper.py` と同じフォルダに置いた `.bat` ファイルを実行します。

		```bat
		@echo off
		cd /d %~dp0
		python json_path_helper.py
		pause
		```

	2.コマンドから直接起動する場合
		```powershell
		python json_path_helper.py
		```

変換ルールの目安（JSON 向け）

JSON の文字列リテラル内では `\` がエスケープ文字として扱われるため、`C:\A\B\C.txt` のような単一バックスラッシュはパースエラーの原因になります。
	二重バックスラッシュ（`\\`）：JSON 仕様どおりにエスケープした形式（外部コマンドや Windows 固有のパス仕様を気にする場合にも無難）
	スラッシュ（`/`）：Python の `open()` や `pathlib.Path` 等でそのまま扱え、手編集時のエスケープ漏れを防ぎやすい形式

## 注意事項
	出力される文字列はパス本体（クォーテーションなし）です。JSON のキーや前後の `"`、カンマ等は必要に応じて編集側で調整してください。
	ネットワークパス（UNC パス）や外部ツールへ渡す際の挙動は、利用先の仕様に合わせて確認してください。
